# jab — class folder

Lead-hand straight punch. Fast, short, minimal body rotation.

Put clips of **only this move** here. The folder name is the label.

**Watch out:** the jab is the easiest move to confuse with the **cross** — both are
straight punches down the centre. The difference is which hand and how much the hips
and shoulders rotate. Film both stances (orthodox and southpaw) so the model learns
the rotation, not just "the right arm moved".

Clips are gitignored; this note keeps the folder in git. See `../noted.md` for the
shared filming guidance.
