# hook — class folder

Horizontal arc punch, elbow bent near 90 degrees, driven by body rotation.

Put clips of **only this move** here. The folder name is the label.

**Watch out:** the hook travels sideways, so a straight-on camera sees it heavily
foreshortened — the wrist barely moves in 2D even though the punch is large. Film
from several angles, including from the side, or this class will be the weakest one.
Include both lead and rear hooks.

Clips are gitignored; this note keeps the folder in git. See `../noted.md` for the
shared filming guidance.
