# cross — class folder

Rear-hand straight punch. Straight like the jab, but slower, longer, with clear hip
and shoulder rotation driving from the back foot.

Put clips of **only this move** here. The folder name is the label.

**Watch out:** most likely to be confused with the **Jab**. The rotation of the hips
is the signal that separates them, so frame the shot to keep the hips visible — a
chest-up crop throws away the one feature that distinguishes these two classes.

Clips are gitignored; this note keeps the folder in git. See `../noted.md` for the
shared filming guidance.
