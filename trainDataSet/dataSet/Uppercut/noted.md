# Uppercut — class folder

Rising vertical punch from below, with a dip in the knees before the drive upward.

Put clips of **only this move** here. The folder name is the label.

**Watch out:** the giveaway is vertical — the dip then the rise. That makes it the
most distinct of the four punches in keypoint space, so it should be the easiest
class. Include both lead and rear uppercuts.

Clips are gitignored; this note keeps the folder in git. See `../noted.md` for the
shared filming guidance.
